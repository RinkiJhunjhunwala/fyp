The Challenge in Healthcare AI

Acute Myocardial Infarction (AMI) is a life-threatening cardiovascular emergency requiring rapid recognition. Modern clinical machine learning models require large, diverse patient datasets to achieve generalizable diagnostic performance.

However, patient medical records are strictly protected by data privacy regulations (e.g. HIPAA, GDPR). Hospitals cannot pool their raw Electronic Health Records (EHR) into a central repository due to legal, privacy, and institutional security restrictions.

Isolated Hospital Bottleneck: Individual hospitals with small cohorts train models that overfit and fail on external populations (e.g., our Hospital B baseline achieved only 31.25% accuracy alone).
🛡️

The Federated Learning Solution (FedAvg)

Federated Learning replaces centralized data pooling with distributed collaborative model training:

  1. Global Initialization: Central server initializes model parameters $(W, b)$.
  2. Parameter Broadcast: The server sends model weights to participating hospitals.
  3. Private Local Training: Each hospital trains locally on its private ICU vitals.
  4. Update Aggregation: Hospitals transmit only parameter updates back.
  5. Federated Averaging: The server computes sample-weighted averages: $$W_{t+1} = \sum_{k} \frac{n_k}{N} W_k^{(t)}$$
Privacy Guarantee: Raw patient records never leave the hospital firewall.

MIMIC-IV v3.1 Clinical Dataset Architecture

Cohort Derivation

Rigorous patient selection from MIMIC-IV v3.1 identifying AMI diagnoses via ICD-9 code 410 and ICD-10 codes I21–I22 with perfectly balanced positive and control cohorts.

Vital Signs Evaluated

High-frequency physiological monitoring: Heart Rate (HR), Systolic BP (SBP), Diastolic BP (DBP), and Pulse Oximetry (SpO₂), reconciled across arterial catheter and non-invasive cuff monitors.

Strict Leakage Prevention

Strict 24-hour observation window from first vital recording. Fixed-length statistical feature vectors (mean, min, max, std, range, first, last, trend, count, shock index) computed per patient.
