\noindent \textbf{Student Academic Profile:}\\
Rinki Jhunjhunwala is a final-year undergraduate student pursuing the Bachelor of Technology (B.Tech.) degree in Computer Science and Engineering at the National Institute of Technology, Agartala. Her academic coursework and project interests include applied machine learning, distributed computing, federated learning in healthcare, clinical data analysis, and web software development.

\vspace{0.8cm}

\noindent \textbf{Summary of Project Contributions:}\\
In this undergraduate capstone project titled \textit{"Privacy-Preserving Cardiovascular Disease Classification Using Federated Learning"}, Rinki carried out the following research and implementation activities:
\begin{itemize}
    \item \textbf{Clinical Data Processing:} Explored the large-scale MIMIC-IV version 3.1 hospital database, audited candidate admissions, and selected an 80-patient balanced ICU cohort (40 AMI cases and 40 control cases) with zero artificial data synthesis.
    \item \textbf{Physiological Feature Engineering:} Developed a clean, leak-free feature extraction pipeline that converted continuous, irregular 24-hour vital signs (Heart Rate, Systolic BP, Diastolic BP, and Oxygen Saturation) into 43 tabular statistical, trend, and hemodynamic ratio features per patient.
    \item \textbf{Centralized Baseline Evaluation:} Built, tuned, and compared six traditional machine learning models (Logistic Regression, Random Forest, Decision Tree, Support Vector Machine, K-Nearest Neighbors, and Gradient Boosting) using 5-fold Stratified Cross-Validation.
    \item \textbf{Federated Learning Simulation:} Implemented the Federated Averaging (FedAvg) protocol across a simulated three-hospital network, demonstrating that collaborative parameter aggregation rescues small, data-starved hospitals without transferring private patient records.
    \item \textbf{Web Application Deployment:} Built an interactive, responsive diagnostic web application using Flask, allowing clinicians to perform real-time risk assessment and explore model performance.
\end{itemize}
